# Bulk MD Tg 150-Polymer Chemical-Diversity Selection\n\nExactly 150 feasible canonical polymers were selected by deterministic Morgan radius-2/2048-bit Butina clustering at Tanimoto 0.65. One feasible representative nearest each cluster medoid was made available, then 150 cluster representatives were selected by deterministic farthest-point traversal in Morgan-fingerprint space. This preserves both small- and large-cluster coverage and prevents dominant-cluster duplication. Only structural inputs were used; no Tg values, Model B predictions/errors, trajectories, or model-performance data were read. Every selected configuration meets the 4–8 chain, DP >=10, 5,000–15,000 atom requirements.\n
